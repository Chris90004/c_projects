Valid indices for an array of length n run from which valueto which value? What does C do if you read scores[n]?
Valid arrays would be from 0 to n-1. scores[n] is accessing memory outside valid boundaries which results in incorrect values.

Why does sizeof(scores) / sizeof(scores[0]) work in main on the actual array, but fail inside a function that took const int scores[]?
inside a function the array paramete is a pointer and returns the size of the pointer not the array.

For int board[3][4], which element is board[1][2] (row, column, and a one-sentence note on row-major layout)?
board[1][2] is second row and third column, zero index.

Why must a function that receives an array also receive the length?
To prevent the funciton from accessing memory outside the array

In your 2D print loop, which index is the row and which is the column? What goes wrong if you swap them?
first index is the row and the second index is the column. Switching these will return incorrect values or be outside the arrays parameters.

What does compiling with -g add that GDB needs? What happens if you forget -g?
-g adds debugging information that makes parsing through variables available. if you dont add -g the program can still be debugged using GDB but not all information is available.
